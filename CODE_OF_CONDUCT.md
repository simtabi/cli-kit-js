# Code of Conduct

This project follows the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: treat everyone with respect. Harassment, discrimination, and personal attacks are not tolerated. Disagree on technical merit, never on personal traits.

## Enforcement

Report concerns to **conduct@simtabi.com**. All reports are reviewed by the maintainers, treated confidentially, and responded to within 7 days. Consequences range from a private warning to a permanent ban depending on severity and pattern.

## Scope

This Code applies to all project spaces — issues, PRs, discussions, code review, social media accounts representing the project, and any in-person or online events.
