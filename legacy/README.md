# Legacy

Frozen snapshot of the pre-redesign implementation. Kept for historical reference only.

- `universal-cli.js` — original ES6 build (1,130 lines)
- `universal-cli-8.js` — byte-identical duplicate of `universal-cli.js` (will be deleted post-1.0)
- `universal-cli-es3.js` — ES3 build for legacy environments
- `example-node-cli.js`, `example-browser.html` — original usage examples
- `universal-cli-README.md` — original documentation

**Do not import from this directory.** The new implementation lives in `packages/`. See the root `README.md`.

This snapshot will be removed at v1.0.0.
