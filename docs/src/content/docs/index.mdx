`cli-kit-js` is the JavaScript implementation of the **cli-kit** family — a multi-language CLI brand. The Python, Go, and Rust siblings share the same design: zero runtime dependencies, safe-by-default rendering, layered config, fluent command builder.

## Quick taste

```ts
import { defineCommand, run } from '@simtabi/cli-kit-js'

const build = defineCommand({
  meta: { name: 'build', version: '1.0.0' },
  args: {
    input:   { type: 'positional', required: true },
    output:  { type: 'string', alias: 'o', default: 'dist/' },
    verbose: { type: 'count', alias: 'v' },
  },
  async run({ args, io, signal }) {
    io.write(`Building ${args.input} → ${args.output}\n`)
  },
})

await run(build)
```
